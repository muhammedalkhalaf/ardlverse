## ardlverse 2.1.0

This release corrects the computations below; the version on CRAN is 2.0.3.

Version 2.1.0 follows 2.0.3 within days because a re-audit found that the bootstrap bounds tests held the regressors fixed and over-rejected, that the analytical verdict was invalid with Fourier terms, and that the mtnardl dynamic multipliers were wrong, so results change.

Monte Carlo rates: y and x independent random walks, n = 100, 200 samples, B = 199, nominal level 5%; Monte Carlo standard errors in parentheses.

* `boot_ardl()`: the bootstrap kept the lagged levels and differences of the data fixed and regenerated only the dependent variable under one null; it rejected in 29.0% (3.2%) (F) and 53.0% (3.5%) (t) of the samples. It is now a recursive bootstrap following Bertelli, Vacca and Zoia (2022, Section 3) by default (separate nulls for Fov, t and Find, x* from the marginal model with p - 1 lags as in BVZ eq. 19, recentring after each draw, random block of initial values continuing the data's levels) or, with `nulls = "joint"`, the Fov null for all statistics (McNown, Sam and Goh, 2018, Steps 1-8) applied to the conditional ECM (package choice). New rejection rates: 4.5% (1.5%) (Fov), 7.5% (1.9%) (t), 10.0% (2.1%) (Find); joint null 7.0% (1.8%), 8.0% (1.9%), 8.5% (2.0%).
* `boot_ardl()`: the decision was "F or t significant"; it is now Fov and t and Find, with the degenerate cases labelled (rate of a "cointegration" decision under the null: 57.5% (3.5%) before, 3.0% (1.2%) now). New outputs `Find_stat`, `decision`; critical values are order statistics; `F_overall` documented as equal to `F_stat`; the documentation no longer claims to follow McNown, Sam and Goh (2018) for a scheme that differed from it. `p = 0` now gives an error (it silently ran the `p = 1` model).
* `aardl()` bootstrap types (`bootstrap`, `bnardl`, `fbootstrap`, `fbnardl`): same defect and same correction, with the partial sums rebuilt from the bootstrap regressors and the Fourier terms held fixed. Rejection rates: before 32.0% (3.3%) to 86.0% (2.5%) (F), 50.5% (3.5%) to 97.5% (1.1%) (t), 18.0% (2.7%) to 49.5% (3.5%) (F_ind); now 4.0% (1.4%) to 9.0% (2.0%), 6.5% (1.7%) to 12.0% (2.3%), 6.5% (1.7%) to 16.0% (2.6%). F_ind over-rejects with Fourier terms and partial sums (16.0% (2.6%); an independent review gave 11.3% (1.8%)); this is documented. Rate of a "cointegration" decision: 14.5% (2.5%) to 47.0% (3.5%) before, 2.0% (1.0%) to 6.0% (1.7%) now.
* `aardl()` types `fourier` and `fnardl`: the bounds decision with Fourier terms is removed (no valid bounds exist; its rejection rate under the null was 22.5% (3.0%) and 28.5% (3.2%)); the bounds shown are labelled as bounds for the model without Fourier terms.
* `mtnardl()`: the dynamic multipliers used the level coefficient as a short-run coefficient (regime 2 at horizon 0: 0.090 instead of 0.303); they are now computed by the full recursion of the estimated ECM and equal the simulated level response to 1e-10. Horizons are 0 to `horizon`. Coefficient names changed (`y_lag`, `dy_l1`, `d_<regime>_l<i>`).
* `mtnardl()`: `auto_select = TRUE` with `n_thresholds = 1` always returned 0 (a silent internal error); it now selects the threshold by AIC.
* `mtnardl()`: bounds with k = number of level regressors by default (`bounds_k` argument); asymptotic decision on F and t; bootstrap replaced by the recursive bootstrap (rejection rates before 46.0% (3.5%) (F) and 73.0% (3.1%) (t); now 3.5% (1.3%), 7.0% (1.8%), 9.5% (2.1%) for Fov, t, Find); delta-method long-run standard errors with the full covariance matrix; joint Wald test of equal long-run coefficients across regimes (chi-squared, R - 1 df); new `decompose` and `threshold_type = "quantile"` options.
* `boot_ardl()`, `aardl()`, `mtnardl()`: transformed terms in the formula (for example `log(y)`) were silently replaced by the untransformed variables; they now give an error. Missing values give an error instead of being dropped. The `seed` argument no longer resets the session's random number generator.
* New function `fbnardl()` (Fourier bootstrap nonlinear ARDL), a port that corrects the defects of the stand-alone GitHub version 1.0.2: long-run asymmetry Wald gradient (631.90 instead of 13.36 in the reference example), fixed-design bootstrap, hard-coded bounds, bounds used with Fourier terms, lag selection on different samples, multipliers without lagged short-run terms, failed replications stored as 0. Default x model of the BVZ bootstrap: marginal model of BVZ eqs. 19-20. Rejection rates with the frequency and lags selected again in each bootstrap sample (package choice; BVZ step 5(c) re-estimates the unrestricted model but does not discuss re-selection): 7.0% (1.8%) (Fov), 11.5% (2.3%) (t), 11.5% (2.3%) (Find) (stand-alone version: 98.5% (0.9%), 99.0% (0.7%), 67.5% (3.3%)).
* DESCRIPTION: the bootstrap is described as following Bertelli, Vacca and Zoia (2022) and McNown, Sam and Goh (2018) instead of "bootstrap-based bounds testing per Pesaran, Shin and Smith (2001)".

Choices pending verification against papers that were not available for this release (documented in the help pages and NEWS as package choices): Pal and Mitra (2016) and Shin, Yu and Greenwood-Nimmo (2014) for k in the bounds of `mtnardl()`, the definition of the dynamic multipliers and the sign convention for negative partial sums, and the short-run symmetry test on the sum over lags in `fbnardl()`; Yilanci, Bozoklu and Gorus (2020) and Omay (2015) for the fractional frequency grid of `fbnardl()` (the default is the integer grid); Sam, McNown and Goh (2019) for the bootstrap details of the augmented ARDL test in `aardl()`.
